# Express Serverstruct Skills

Reusable AI agent skills for building with [express-serverstruct](https://github.com/eriicafes/express-serverstruct).

## Install

```sh
npx skills add eriicafes/express-serverstruct
```

## Available Skills

| Skill                                                     | Description                                                                                                                |
| --------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| [`express-serverstruct`](./express-serverstruct/SKILL.md) | Server lifecycle, route modules, controllers, validation, request context, structured errors, and OpenAPI docs with Scalar |
